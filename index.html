Key Financial Formulae

NPV:

\[ \mathrm{NPV} = \sum_{t=1}^{T} \frac{CF_t}{(1+r)^t} - C_0 \]

CAGR:

\[ \mathrm{CAGR} = \left(\tfrac{V_f}{V_i}\right)^{1/n} - 1 \]

EPS:

\[ \mathrm{EPS} = \frac{\text{Net Income} - \text{Preferred Dividends}}{\text{Weighted Avg. Shares}} \]

VaR (variance-cov) (1-day):

\[ \mathrm{VaR}_{\alpha} = z_{\alpha} \cdot \sigma_P \cdot \sqrt{\Delta t} \]

Code Sample: CAGR Calculation (Python)

def cagr(ending, beginning, years):
    """Compound Annual Growth Rate"""
    return (ending / beginning) ** (1/years) - 1

print("CAGR:", round(cagr(8.4, 6.7, 3)*100, 2), "%")
